# AI Courier Tracking Assistant

## 1. Project Overview

The AI Courier Tracking Assistant is an AI and Data Science project designed to help customers track courier shipments and receive automated support.

The system combines:

- Machine Learning
- Natural Language Processing
- Generative AI
- Shipment tracking
- Customer support automation
- Streamlit-based web applications

The system uses historical courier delivery data to provide shipment information and predict delivery duration.

---

## 2. Project Objective

The main objective is to develop an intelligent courier tracking system that can:

- Accept customer tracking queries
- Extract tracking IDs from customer messages
- Identify customer intent
- Retrieve shipment information
- Predict delivery duration
- Generate natural-language responses
- Provide a tracking dashboard
- Provide a customer support portal
